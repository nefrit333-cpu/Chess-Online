# 🧙‍♂️ Шахматы Гарри Поттера с ИИ

**🌐 [ИГРАТЬ ОНЛАЙН](https://haze13.github.io/Chess-Online/chess-game/index.html)** | [Политика конфиденциальности](PRIVACY.md) | [Отказ от ответственности](DISCLAIMER.md)

Веб-версия шахматной игры с искусственным интеллектом в стилистике фильмов о Гарри Поттере.

## ✨ Особенности

- **Магический дизайн**: Темная тема с золотыми акцентами, вдохновленная эстетикой Гарри Поттера
- **Искусственный интеллект**: Играйте против компьютера с алгоритмом оценки позиций
- **Сохранение прогресса**: Автоматическое сохранение партии в localStorage браузера
- **Полные правила шахмат**: 
  - Рокировка (короткая и длинная)
  - Взятие на проходе (en passant)
  - Превращение пешки
  - Шах, мат и пат
- **История ходов**: Отслеживание всех сделанных ходов
- **Адаптивный дизайн**: Работает на десктопах и мобильных устройствах

## 🚀 Быстрый старт

1. Клонируйте репозиторий:
```bash
git clone <URL-репозитория>
cd Chess-Online
```

2. Откройте файл `chess-game/index.html` в любом современном браузере

Или используйте локальный сервер:
```bash
# Python 3
python -m http.server 8000

# Node.js (требуется http-server)
npx http-server
```

Затем откройте `http://localhost:8000/chess-game/index.html`

## 🎮 Как играть

1. **Белые фигуры** ходят первыми (игрок)
2. Кликните на фигуру для выбора
3. Зеленые точки покажут доступные ходы
4. Кликните на целевую клетку для хода
5. ИИ (черные фигуры) ответит автоматически

## 💾 Сохранение и загрузка

- Игра автоматически сохраняется после каждого хода
- Кнопка **"Продолжить игру"** загружает последнее сохранение
- Кнопка **"Удалить сохранение"** очищает сохраненную партию
