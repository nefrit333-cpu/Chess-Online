# 🛡️ Политика конфиденциальности

## Дата вступления в силу: 2026

## 1. Общие положения

Эта политика конфиденциальности описывает, как проект "Шахматы Гарри Поттера с ИИ" (далее - "Проект") обрабатывает данные пользователей.

**Ключевой принцип**: Проект НЕ собирает, НЕ хранит и НЕ передает персональные данные пользователей.

---

## 2. Какие данные мы НЕ собираем

Проект полностью клиентский и не имеет серверной части. Мы **НЕ собираем**:

- ❌ Имена и фамилии
- ❌ Адреса электронной почты
- ❌ IP-адреса
- ❌ Геолокацию
- ❌ Данные об устройстве
- ❌ Историю браузера
- ❌ Файлы cookie для отслеживания
- ❌ Аналитические данные
- ❌ Любые другие персональные данные

---

## 3. Локальное хранение данных

### 3.1 LocalStorage браузера

Проект использует технологию **localStorage** для сохранения игрового прогресса.

**Что сохраняется:**
- Текущее состояние шахматной доски
- История ходов
- Информация о рокировках
- Статус игры

**Характеристики хранения:**
- ✅ Данные хранятся ТОЛЬКО на устройстве пользователя
- ✅ Данные доступны ТОЛЬКО из этого проекта
- ✅ Данные НЕ передаются на сервер
- ✅ Пользователь может удалить данные в любой момент

### 3.2 Как управлять сохраненными данными

**Просмотр данных:**
```javascript
// Откройте консоль браузера (F12) и выполните:
console.log(localStorage.getItem('chessGame'));
```

**Удаление данных через интерфейс:**
- Используйте кнопку "Удалить сохранение" в игре

**Удаление данных через браузер:**
1. Откройте настройки браузера
2. Перейдите в раздел "Конфиденциальность" или "История"
3. Найдите данные сайта
4. Удалите данные для домена проекта

**Удаление через консоль:**
```javascript
// Очистить сохранение игры
localStorage.removeItem('chessGame');

// Очистить все данные проекта
localStorage.clear();
```

## 5. Безопасность данных

### 5.1 Защита локальных данных

Хотя данные хранятся только локально, рекомендуем:

- Не используйте проект на общественных компьютерах для важных партий
- Регулярно очищайте кэш браузера при необходимости
- Используйте современные браузеры с актуальными обновлениями безопасности

### 5.2 Ограничения localStorage

Пользователи должны знать:
- Данные могут быть удалены при очистке кэша браузера
- Данные привязаны к конкретному браузеру и устройству
- При переходе на другое устройство прогресс не синхронизируется
- Некоторые браузеры могут ограничивать размер localStorage (обычно 5-10 МБ)

## 6. Права пользователей

Согласно различным законам о защите данных (GDPR, CCPA и др.), пользователи имеют права:

### 6.1 Право на доступ
Вы можете просмотреть все сохраненные данные через консоль браузера.

### 6.2 Право на исправление
Вы можете изменить данные, продолжив игру и сделав новые ходы.

### 6.3 Право на удаление
Вы можете удалить данные:
- Через интерфейс игры (кнопка "Удалить сохранение")
- Через настройки браузера
- Через консоль разработчика

### 6.4 Право на переносимость
Данные можно экспортировать через консоль:
```javascript
// Экспорт сохранения
const data = localStorage.getItem('chessGame');
console.log(data);
// Скопируйте вывод и сохраните в файл
```

Импортировать можно через:
```javascript
// Импорт сохранения (замените YOUR_DATA на ваши данные)
localStorage.setItem('chessGame', 'YOUR_DATA');
location.reload();
```

### 6.5 Право на ограничение обработки
Просто не используйте проект - никакие данные не будут созданы.

## 10. Соответствие регуляциям

### 10.1 GDPR (General Data Protection Regulation)

Проект соответствует GDPR потому что:
- ✅ Не собирает персональные данные
- ✅ Данные хранятся локально на устройстве пользователя
- ✅ Пользователь имеет полный контроль над данными
- ✅ Нет трансграничной передачи данных

**Правовое основание**: Обработка не требуется, так как данные не собираются.

### 10.2 CCPA (California Consumer Privacy Act)

Проект соответствует CCPA потому что:
- ✅ Не продает персональные данные
- ✅ Не собирает персональные данные
- ✅ Предоставляет право на удаление

### 10.3 COPPA (Children's Online Privacy Protection Act)

Проект соответствует COPPA потому что:
- ✅ Не собирает данные от детей до 13 лет
- ✅ Не требует регистрации
- ✅ Нет таргетированной рекламы

### 10.4 Другие юрисдикции

Проект разработан с учетом лучших практик защиты данных и должен соответствовать:
- PIPEDA (Канада)
- LGPD (Бразилия)
- PDPA (Сингапур, Таиланд)
- Другим национальным законам о защите данных

## 11. Часто задаваемые вопросы

### ❓ Сохраняется ли моя игра на сервере?
**Нет.** Все данные хранятся только в вашем браузере.

### ❓ Могут ли другие люди увидеть мои партии?
**Нет**, если только вы сами не предоставите им доступ к вашему устройству или не экспортируете данные.

### ❓ Что произойдет если я очищу кэш браузера?
Сохраненная игра будет удалена. Рекомендуется завершить партию перед очисткой кэша.

### ❓ Могу ли я играть без интернета?
**Да.** После первой загрузки страницы проект работает офлайн.

### ❓ Используете ли вы cookie?
**Нет.** Проект не использует cookie для отслеживания.

### ❓ Передаете ли вы данные третьим лицам?
**Нет.** Данные вообще никуда не передаются.
